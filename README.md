<div align="center">

| **Création** | **Infrastructure** | **Exploitation** |

<details>
<summary><b>Voir le détail des offres</b></summary>

<br/>

- **Création** : sites, applications métiers, intégration IA, avec devis écrit avant démarrage  
- **Domaines** : recherche, commande, DNS, transfert, privacy  
- **Hébergement** : VPS, console, monitoring, sauvegardes  
- **Messagerie** : boîtes professionnelles et webmail  
- **Maintenance** : suivi, sécurité et évolutions au forfait ou sur devis  
- **Espace client** : demandes, devis, factures, panier, messages avec l’équipe
